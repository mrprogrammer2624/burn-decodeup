# Responsive Landing Page Hero Section

## Overview
A responsive hero section with a collapsible mobile navbar, built with semantic HTML5, CSS3 (Flexbox + Media Queries), and JavaScript for interactivity.

## Features
- Mobile-first responsive layout
- Hamburger menu toggle
- Semantic HTML structure
- Smooth button actions with JavaScript
- Modern design with CTA buttons and image

## Setup
1. Clone the repo or unzip the folder.
2. Open `index.html` in your browser.
